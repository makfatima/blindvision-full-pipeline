# IEEE Submission Cover Letter

**Manuscript:** *BlindVision: A Dual-Device Sensor-Fusion System for Assistive Navigation — Implementation and Experimental Validation*

Dear Editor / Review Committee,

Please consider our manuscript, “BlindVision: A Dual-Device Sensor-Fusion System for Assistive Navigation — Implementation and Experimental Validation,” for publication in **[TARGET IEEE VENUE]**.

The manuscript presents a dual-device assistive-navigation prototype combining wearable vision on Raspberry Pi 4-based Smart Goggles with independent ground-level sensing on an ESP32-based Smart Stick. The system integrates on-device object detection, rule-based sensor fusion, multimodal alerts, BLE communication, and a caregiver/backend layer.

The full-system evaluation comprises 20 sessions and 100 navigation trials covering approximately 2 km. The reported results include a 96.0% overall navigation success rate (96/100), 99.0% BLE packet delivery (7920/8000), 96.7% ultrasonic hazard detection (174/180), 98.4% water-hazard detection accuracy, and 100% SOS detection (20/20). The manuscript reports a 205 ms single-stream processing-path estimate and separately reports 22.8 FPS aggregate throughput under four-camera operation.

The manuscript explicitly distinguishes measured quantities from derived quantities and describes the limits of the available experimental records. In particular, a quantitative paired Vision-Only/Stick-Only/Fused ablation is not claimed because trial-level correspondence is unavailable. Battery-runtime figures are identified as analytical projections from discharge measurements, and the available data/model artifacts are described according to their actual release scope.

The accompanying repository contains the implementation, configuration, evaluation utilities, tests, documentation, and released experimental/result records corresponding to the manuscript.
