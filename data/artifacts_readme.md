# Experimental data and result artifacts

This directory contains the experimental measurements and derived result tables accompanying BlindVision.

The retained records cover the ten-class detection evaluation (including the per-class confusion matrix, data/Confusion_Matrix.csv), participant-level navigation outcomes (a per-tester breakdown, not a disability-status breakdown — see data/raw/README.md), BLE communication, power measurements, arbitration configuration, and aggregate trial/session results reported in the manuscript.

The complete image/label dataset, trained model weights, epoch-wise training logs, and raw confusion-matrix event data are not included in this release, consistent with the manuscript's Data Availability statement.
