# BlindVision 10-Class Dataset Scaffold — TEST ONLY

Classes: person, door, chair, backpack, laptop, bottle, pole, vehicle, bicycle, stairs

This is a training/data scaffold, not experimental evidence. The image files are
placeholders and must be replaced with appropriately licensed images and real
YOLO annotations before any new training run. It must not be represented as
the historical dataset used for the manuscript's reported results.
