# IEEE Submission Cover Letter Draft

Dear Editor,

Please consider the manuscript entitled “BlindVision: A Dual-Device Sensor-Fusion System for Assistive Navigation — Implementation and Experimental Validation” for publication in [TARGET IEEE VENUE].

This work presents a dual-device assistive-navigation prototype that combines wearable vision on Raspberry Pi 4-based Smart Goggles with independent ground-level sensing on an ESP32-based Smart Stick. The system uses rule-based sensor fusion, multimodal alerts, BLE communication, and a caregiver/backend layer.

The manuscript reports experimental evaluation of the integrated prototype across 20 sessions and 100 navigation trials, together with detection, communication, hazard-sensing, latency, power, computational, and reliability measurements. The reported results include 96.0% overall navigation success, 99.0% BLE packet delivery, 96.7% ultrasonic hazard detection, 98.4% water-hazard detection accuracy, 100% SOS detection, and a 205 ms single-stream processing-path estimate. The manuscript explicitly distinguishes directly measured quantities from derived quantities and identifies the limitations of the current evaluation scope.

The accompanying software release contains the implementation, configuration, evaluation utilities, tests, documentation, and the released experimental/result records described in the manuscript. Data and artifacts subject to the study's data-handling constraints are described explicitly in the manuscript's Data Availability statement.
